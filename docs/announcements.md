## Agenthon 2026 Development Is Now Open — Starter Packages Available

*Friday, August 28, 2026, 07:59 PM EDT*

Welcome to Agenthon 2026, and thank you for registering.

The moment has arrived: Development is now OPEN, and it runs through 28 September. Time to build.

### Your starter packages

Everything you need to get started is now available in our GitHub repositories. We recommend beginning with the competition overview and then moving to the repository for your track.

**Competition overview:** https://github.com/Agenthon-2026/Agenthon2026-public

**T1 Coding — Quant-Finance Coding Agents:** https://github.com/Agenthon-2026/track1-coding-public
Build agents that solve quantitative-finance coding problems. Evaluation focuses on producing correct executable solutions, using pass@1 / pass@3 together with unit tests and financial-invariant checks.

**T2 Forecasting — Reasoning-Augmented Time Series:** https://github.com/Agenthon-2026/track2-forecasting-public
Build agents for probabilistic financial time-series forecasting using the information available at the specified point in time. Evaluation uses a CRPS-based composite score, together with the track's cutoff and calibration requirements.

**T3 Simulation — Accelerated Market Simulation:** https://github.com/Agenthon-2026/track3-simulation-public
Build accelerated financial-market simulators while preserving the required market semantics and statistical behavior. Performance is measured in events per second among admissible submissions — correctness first, then speed.

**T4 Explainability — Evidence-Grounded Prediction:** https://github.com/Agenthon-2026/track4-analysis-public
Build agents that make financial predictions and support them with evidence from the information available to them. Evaluation considers prediction quality and coverage, subject to faithfulness and embargo requirements.

The starter repositories include the materials needed to begin developing and testing your systems, including public practice tasks or scenarios, runnable baselines, local evaluation tools, and participant documentation.

We strongly recommend running the provided baseline and local evaluation pipeline end to end before developing your own approach.

The public materials are intended for development and validation. Final evaluation will use sealed held-out tasks and data that are not included in the public repositories.

The repositories will continue to evolve during the Development phase, so please check back regularly for updates.

The same links are available on the Resources page once you are logged in: https://www.agenthon.net/resources/

## Welcome to Agenthon 2026!

*Friday, July 3, 2026, 11:17 AM EDT*

Alphathon 2026 is now Agenthon 2026.

Agenthon 2026 is a NeurIPS 2026 Competition Track on verifiable AI for quantitative finance, organized by the Society of Quantitative Analysts (SQA) and the Center of Excellence in Wireless and Information Technology (CEWIT) at Stony Brook University.

It extends the Alphathon program into its first NeurIPS edition — keeping the four-track, hard finance setting while adding sealed held-out data, automated leakage controls, reproducible reruns, and public leaderboards. Across the four tracks, the competition tests whether AI agents can produce finance outputs that survive automated, leakage-controlled, cheat-resistant evaluation.
